**AI / RL for Quantum Systems & Software** 为主线；以 **IR / RecSys / Agentic Search** 建立第二能力栈，探索量子优化与检索推荐的交叉问题。

## 三条相互连接的能力线

| 能力线 | 学习顺序 | 作用 |
| :--- | :--- | :--- |
| AI 与决策 | ML / DL → RL → MARL | 理解模型、训练、决策与协作 |
| 量子系统 | 态与测量 → 噪声 / QEC → 编译 → AI for Quantum | 从第一月并行，连接真实任务约束 |
| 检索与优化 | IR / RecSys → Agents → 量子优化交叉 | 理解问题建模、评价与端到端成本 |

## 学习约定

- **每门课先看知识地图。** 先清楚课程包含什么、模块如何关联、重点和先修，再进入章节。
- **经典基础 + 较新前沿。** [版本档案](MATERIAL_VERSIONS.md)分别记录教材、课件与录像。
- **按需补数学。** 围绕当前主题补充线性代数、概率、梯度与优化。
- **实践回答具体问题。** 记录假设、条件、观察和限制，以概念解释和实验分析检验理解。
- **每次最多两条学习线。** 复习、补充阅读和实践均计入每周学习时间。
